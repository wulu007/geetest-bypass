# Geetest v4 全题型性能与准确率基准 (Benchmark)

[English](BENCHMARK.md) | 简体中文

> 本报告基于真实线上环境全自动连续采样评测，展示 `wulu-geetest-bypass` 各验证码题型的综合识别率与耗时表现。
> 各题型分批测试，测试时间见总览表；`–` 表示该项未测或样本不足。

> **指标说明**：
> - **首猜通过率**：无重试的单次提交成功概率 = `通过数 / 总提交数`；**置信区间**为 Wilson 95% 区间，样本越少区间越宽，对比两个题型时请以区间为准。
> - **重试 1 次（推算）**：按 `1 − (1 − p)²` 推算，并非实测。
> - **算法 P50**：纯本地 CPU 的图像预处理、模型推理与坐标指派耗时，仅取线上样本（与通过率同一批题目）。离线 benchmark 数据见第 2.2 节，不参与总览。
> - **端到端 P50**：`load` → `verify` 的完整周期，含网络，随出口 IP 与网络状况波动。
